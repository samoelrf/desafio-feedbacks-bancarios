# Bradesco | Detecção de Fraudes em Cartões com Machine Learning

Projeto desenvolvido durante o **Bootcamp Bradesco - GenAI, Dados & Cyber**.

## Objetivo

Desenvolver um modelo de **Machine Learning capaz de identificar transações fraudulentas em cartões de crédito**, trabalhando com um dataset altamente desbalanceado.

## Tecnologias

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest
* XGBoost
* SHAP
* Matplotlib
* Seaborn

## O que foi desenvolvido

* Análise exploratória dos dados
* Tratamento do desbalanceamento das classes
* Feature Engineering
* Normalização dos dados
* Regressão Logística
* Random Forest
* XGBoost
* Ajuste de threshold
* Avaliação com Precision, Recall e F1-score
* Curva ROC e Precision-Recall
* Feature Importance
* Interpretabilidade com SHAP
* Testes com Undersampling e Oversampling

## Resultado

O projeto compara diferentes modelos de classificação com foco principalmente na **detecção da classe fraudulenta**, utilizando métricas como **Precision, Recall e F1-score**.

### Melhor resultado observado inicialmente

**Random Forest**

* Precision: **0.96**
* Recall: **0.76**
* F1-score: **0.85**

## Dataset

Dataset público de transações de cartões de crédito, carregado diretamente por URL.
O arquivo de dados não é armazenado no repositório.

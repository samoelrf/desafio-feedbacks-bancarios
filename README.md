# Desafio DIO – Extração de Insights de Feedbacks Bancários com IA

Este repositório contém o desafio da Digital Innovation One (DIO) sobre análise de feedbacks bancários utilizando Inteligência Artificial.  
O objetivo é criar um prompt eficiente para que uma IA identifique padrões de satisfação e insatisfação em comentários de clientes sobre serviços bancários digitais.

## 📋 Conteúdo
- Prompt final estruturado com contexto, instruções e restrições.
- Exemplo de resposta simulada da IA com resumo executivo, tabela de sentimentos e recomendações práticas.

## 🚀 Tecnologias e conceitos
- Engenharia de Prompt
- Análise de Sentimentos
- Experiência do Cliente (CX)
- Inteligência Artificial aplicada a dados textuais
